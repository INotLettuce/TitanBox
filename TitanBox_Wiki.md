# TitanBox

TitanBox is a mod of [JukeBox](https://beepbox.miraheze.org/wiki/JukeBox), first published on October 1, 2026, by InotLettuce. Its goal is to bring useful features from different BeepBox mods together in one place. Current TitanBox additions include changes to the editor interface and FM instruments with up to eight operators.

JukeBox is part of the BeepBox mod family. Its upstream lineage runs through Slarmoo's Box, UltraBox, and JummBox back to the original BeepBox.

## Features

### FM instruments

TitanBox adds FM instruments with up to eight operators. The operators can be connected in different arrangements, allowing more involved FM patches. The editor also supports four- and six-operator FM instruments.

### Instrument types

The instrument menu includes several kinds of synthesis:

- Chip and custom chip waves
- FM, including 4-, 6-, and 8-operator instruments
- Noise and spectrum
- Harmonics and picked string
- PWM and supersaw
- Drumset and mod instruments

### Effects

Available effects and controls include reverb, chorus, panning, distortion, bitcrusher, note filtering, echo, pitch shift, detune, vibrato, ring modulation, granular processing, and phaser. The editor also has transition and chord options.

### Interface

TitanBox includes changes to the editor interface. The goal is to make features from different BeepBox mods available together in one editor.

## Presets

The preset menu includes imported collections from other mods. Current named groups include:

- Slarmoo's Box and UltraBox
- Sandbox
- Midbox, including a separate Dubstep group
- AbyssBox
- AwesomeBox
- Studio Box (compatible presets)
- Dogebox2 and BulbBox
- 41Box archive

These are preset collections; their presence does not mean every engine feature came from the same mod. The preset list may change as TitanBox develops.
